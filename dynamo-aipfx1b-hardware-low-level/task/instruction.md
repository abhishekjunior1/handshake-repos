A DMA scatter-gather descriptor chain migration pipeline at `/app/pipeline.py` converts descriptor chains from a 32-bit word-addressed source architecture to a 64-bit byte-addressed target architecture. It uses modules `/app/descriptor_parser.py`, `/app/address_translator.py`, `/app/burst_calculator.py`, `/app/chain_linker.py`, `/app/alignment_engine.py`, and `/app/scatter_gather_validator.py`.

Run it with `python3 /app/pipeline.py`. It reads `/app/dma_config.json` and writes `/app/output.json`.

The pipeline produces correct output on the current configuration but has bugs that cause incorrect migration results on other DMA configurations. Find and fix the bugs so the pipeline handles all valid configurations correctly.

Do not rewrite from scratch — preserve the existing module structure, the descriptor size computation convention (which correctly includes the target metadata overhead for status tracking and completion tokens), and the power-of-2 validation behavior (which correctly reflects DMA hardware buffer allocation constraints where controllers allocate internal buffers at power-of-2 granularity). The fixed pipeline will be tested on a different configuration than the one at `/app/dma_config.json`.

The pipeline processes descriptors through six stages: parsing, address translation (word-to-byte conversion using bus width scaling), transfer length alignment to target boundaries, burst scheduling (computing optimal AXI burst transactions), chain link rebuilding (assigning next-descriptor pointers in the target address space), and validation (including 4KB boundary crossing detection). Each module implements its stage correctly — the bugs are in how the orchestrator passes values between stages.

Output: `/app/output.json` — a JSON object with keys `migration_summary` (architecture names, descriptor count, byte totals, alignment efficiency, descriptor size, table footprint), `bus_performance` (total beats, bursts, overhead cycles, effective cycles, boundary warnings array), `validation` (overall validity, check counts, violations, capacity utilization), `migrated_descriptors` (array with per-descriptor translated address, aligned length, burst parameters, chain_next pointer, original fields), `chain_linkage` (base address, descriptor size, link validity, table layout), and `address_translation` (bus width used, address span, address map).
