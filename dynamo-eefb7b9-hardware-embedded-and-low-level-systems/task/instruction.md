An SPI/I2C peripheral initialization pipeline at `/app/pipeline.py` orchestrates boot-time configuration for peripherals on a shared bus. It uses modules `/app/clock_config.py`, `/app/bus_arbiter.py`, `/app/register_programmer.py`, `/app/device_enumerator.py`, `/app/power_sequencer.py`, and `/app/init_reporter.py`.

Run it with `python3 /app/pipeline.py`. It reads `/app/input.json` and writes `/app/output.json`.

The pipeline produces correct output on the current input configuration but has bugs that cause incorrect results on other configurations (different clock sources, multiple peripherals, various bus topologies). Find and fix the bugs so the pipeline handles all valid configurations correctly.

Do not rewrite from scratch — preserve the existing module structure. In particular, preserve the reverse power domain sequencing (inner-to-outer enable order is correct for hardware that declares domains outer-to-inner) and the 8-bit register access for device enumeration (I2C standard mandates byte-level access before auto-increment is configured). The fixed pipeline will be tested on a different configuration than the one at `/app/input.json`.

Output: `/app/output.json` — a JSON object with sections: `initialization_summary` (total_init_time_us, all_peripherals_initialized, devices_programmed, devices_lost, devices_enumerated, power_domains_enabled, bus_protocol), `clock_configuration` (system_clock_mhz, bus_clock_mhz, peripheral_divider, pll_lock_time_us, clock_gating_mask, pll_enabled, clock_stable_at_t0), `power_sequencing` (enable_sequence with domain entries, total_power_up_time_us, sequencing_valid, domain_count), `bus_transactions` (cs_sequence, deassert_signals, timing), `register_programming` (total_registers_programmed, total_registers_lost, per_device_results, all_devices_successful), `device_enumeration` (total_devices_scanned, devices_identified, devices_mismatched, enumeration_complete), and `diagnostics` (clock_stable_at_programming, peripheral_clock_mhz, bus_contention_detected, bus_issues, cs_sequence).
