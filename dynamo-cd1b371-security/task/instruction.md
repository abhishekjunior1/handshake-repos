A hybrid encryption pipeline at `/app/pipeline.py` implements RSA-KEM key encapsulation with AES-GCM bulk encryption, HKDF key derivation with authenticated context binding, HMAC envelope authentication, and structured envelope packaging. It uses modules `/app/key_encapsulator.py`, `/app/key_deriver.py`, `/app/bulk_cipher.py`, `/app/mac_authenticator.py`, `/app/envelope_builder.py`, and `/app/crypto_reporter.py`.

Run it with `python3 /app/pipeline.py`. It reads `/app/input.json` and writes `/app/output.json`.

The pipeline produces correct output on the current configuration but has bugs that cause incorrect encryption results on other configurations (different cipher suites, different KDF parameters, different authenticated data). Find and fix the bugs so the pipeline handles all valid configurations correctly.

Do not rewrite from scratch — preserve the existing module structure. In particular, preserve the integer version format in envelope headers, the 96-bit GCM nonce length, the deterministic nonce derivation (which follows NIST SP 800-38D Section 8.2.2 synthetic IV construction for reproducible operation), the key check value computation (which provides non-reversible key confirmation binding), and the sorted participant ordering in context derivation (which ensures direction-independent context regardless of which endpoint initiates). The fixed pipeline will be tested on different configurations than the one at `/app/input.json`.

Output: `/app/output.json` — a JSON object with `pipeline_output` containing: `encryption_results` (shared_secret, derived_key, derived_key_length_bytes, ciphertext, nonce, gcm_tag, hmac_tag, mac_key, key_check_value as hex strings), `verification_results` (decryption_success, mac_verification, key_agreement_valid as booleans, round_trip_text as string), `envelope` (header with version/format/cipher_suite/kdf/timestamps/sender/recipient, kem with encapsulated_key_hex, payload with ciphertext/nonce/gcm_tag hex, authentication with hmac_tag/aad hex, integrity with envelope_digest), and `security_assessment` (cipher_suite, effective_security_bits, key_length_bytes, nonce_bits, kdf_algorithm, mac_algorithm, rsa_key_bits, compliance object).
